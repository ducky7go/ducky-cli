# 🔥 상처를 온기로

게임에서 피해를 입을 때 이 모드는 자동으로 추위 및 동상 상태를 해제하여 전투 중 따뜻하고 편안하게 유지해줍니다.

## ✨ 주요 기능

- **자동 부정적 효과 해제**: 피해를 입을 때 자동으로 추위 및 동상 버프 제거
- **즉시 활성화**: 피해를 입은 즉시 효과 발동, 수동 조작 불필요
- **전투 상태 유지**: 추위 효과로 인한 전투 성능 저하 방지
- **가벼운 설계**: 최소한의 리소스 사용, 게임 성능에 영향 없음

## 🎮 사용 방법

모드가 자동으로 실행되며 설정이 필요하지 않습니다. 적이나 환경으로부터 피해를 입으면 추위 및 동상 상태가 즉시 해제됩니다.

## ⚠️ 중요 사항

- 피해를 입을 때만 발동하며, 추위 상태를 능동적으로 예방하지 않음
- 다른 모드와 호환되며 충돌 없음
- 싱글플레이어 및 멀티플레이어 모두에서 작동

## 🔧 기술적 세부사항

- 모든 피해 유형 감지 (적 공격, 환경 피해, 낙하 피해 등)
- 추위 관련 버프의 스마트 인식으로 정확한 상태 해제
- 효율적인 이벤트 리스닝 메커니즘으로 빠른 응답 보장
