# 🔥 Рана в Тепло

Когда вы получаете урон в игре, этот мод автоматически очищает ваш статус холода и обморожения, сохраняя вас в тепле и комфорте во время боя.

## ✨ Ключевые Особенности

- **Автоматическое Очищение Негативных Эффектов**: Автоматически удаляет баффы холода и обморожения при получении любого урона
- **Мгновенная Активация**: Действует немедленно при получении урона, без ручного управления
- **Поддержание Боевого Статуса**: Избегает ухудшения боевых характеристик из-за эффектов холода
- **Легковесный Дизайн**: Минимальное использование ресурсов, без влияния на производительность игры

## 🎮 Как Использовать

Мод работает автоматически без необходимости настройки. Когда вы получаете урон от врагов или экологических опасностей, ваш статус холода и обморожения будет немедленно очищен.

## ⚠️ Важные Заметки

- Срабатывает только при получении урона, не предотвращает проактивно статус холода
- Совместим с другими модами, без конфликтов
- Работает как для одиночных, так и для многопользовательских игр

## 🔧 Технические Детали

- Обнаруживает все типы урона (включая атаки врагов, экологический урон, урон от падения и т.д.)
- Умное распознавание баффов, связанных с холодом, для точного очищения статуса
- Эффективный механизм прослушивания событий обеспечивает быстрый ответ
